Mise en forme des supports d'atelier

Deux façons de générer un support au gabarit du Département, entièrement dans votre navigateur (aucun fichier n'est envoyé à un serveur, y compris pour la lecture des captures ci-dessous).

Déposez le PPTX source de votre atelier : il sera automatiquement mis en forme selon le gabarit du Département.

Glissez votre fichier .pptx ici

ou cliquez pour sélectionner un fichier

Déposez des captures d'écran (.png/.jpg) d'un parcours PIX : chaque capture est lue localement (reconnaissance de texte hors-ligne) puis rapprochée d'une bibliothèque de thèmes pédagogiques pour composer un support de préparation — pas un quiz, pas les réponses.

Glissez vos captures PIX ici (plusieurs fichiers possibles)

ou cliquez pour sélectionner des fichiers

Vos propres illustrations, réparties sur les diapositives générées. Les thèmes non couverts utilisent un pictogramme générique à la place.

Repartez d'un ancien support (.pptx) et enrichissez-le avec des captures PIX. Les thèmes PIX sont toujours conservés en priorité ; s'il y a doublon avec une diapositive de l'ancien support sur le même sujet, c'est la version PIX qui est gardée. La séance est calée sur ~ minutes, à raison d'environ minutes par section — le contenu de l'ancien support est réduit en premier si ça ne rentre pas.

Glissez l'ancien fichier .pptx ici

ou cliquez pour sélectionner un fichier

Glissez les captures PIX ici (plusieurs fichiers possibles)

ou cliquez pour sélectionner des fichiers

Réparties sur les diapositives issues des captures PIX ; pictogramme générique à défaut.

Si ce champ est laissé vide, le titre trouvé dans le fichier source sera utilisé (mode PPTX) ; à défaut, un message d'alerte rouge apparaîtra à sa place dans le livrable pour que vous le complétiez manuellement.

Si ce champ est laissé vide et qu'aucune information équivalente n'est trouvée dans le fichier source, un message d'alerte rouge apparaîtra à sa place dans le livrable pour que vous le complétiez manuellement.
