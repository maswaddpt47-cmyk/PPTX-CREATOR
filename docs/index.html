Mise en forme des supports d'atelier

Déposez le PPTX source de votre atelier : il sera automatiquement mis en forme selon le gabarit du Département, entièrement dans votre navigateur (aucun fichier n'est envoyé à un serveur).

Glissez votre fichier .pptx ici

ou cliquez pour sélectionner un fichier

Si ce champ est laissé vide, le titre trouvé dans le fichier source sera utilisé. À défaut, un message d'alerte rouge apparaîtra à sa place dans le livrable pour que vous le complétiez manuellement.

Si ce champ est laissé vide et qu'aucune information équivalente n'est trouvée dans le fichier source, un message d'alerte rouge apparaîtra à sa place dans le livrable pour que vous le complétiez manuellement.
