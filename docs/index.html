Mise en forme des supports d'atelier

Deux façons de générer un support au gabarit du Département, entièrement dans votre navigateur (aucun fichier n'est envoyé à un serveur, y compris pour la lecture des captures ci-dessous).

Déposez le PPTX source de votre atelier : il sera automatiquement mis en forme selon le gabarit du Département.

ou cliquez pour sélectionner un fichier

À raison d'environ minutes par section, les dernières sections de la source sont réduites si ça ne rentre pas.

Déposez des captures d'écran (.png/.jpg) d'un parcours PIX : chaque capture est lue localement (reconnaissance de texte hors-ligne) puis rapprochée d'une bibliothèque de thèmes pédagogiques pour composer un support de préparation — pas un quiz, pas les réponses.

ou cliquez pour sélectionner des fichiers

À raison d'environ minutes par thème, les thèmes les moins confirmés par vos captures sont réduits en premier si ça ne rentre pas.

Vos propres illustrations, réparties sur les diapositives générées. Les thèmes non couverts utilisent un pictogramme générique à la place.

Repartez d'un ancien support (.pptx) et enrichissez-le avec des captures PIX. Les thèmes PIX sont toujours conservés en priorité ; s'il y a doublon avec une diapositive de l'ancien support sur le même sujet, c'est la version PIX qui est gardée. Le contenu de l'ancien support est réduit en premier si la séance ne rentre pas dans la durée cible ci-dessous.

À raison d'environ minutes par section, ça fixe le nombre maximum de sections retenues.

Réparties sur les diapositives issues des captures PIX ; pictogramme générique à défaut.

Déposez plusieurs anciens PPTX (ancienne charte) : ils sont fusionnés en un seul livrable au nouveau gabarit. Chaque source garde ses propres sections, dans l'ordre de dépôt ; le contenu très proche d'une source à l'autre n'est gardé qu'une seule fois (la première source déposée est prioritaire en cas de recoupement).

À raison d'environ minutes par section, les dernières sections (des sources les plus tardives) sont réduites en premier si ça ne rentre pas.

Pas de PPTX de départ : donnez juste le thème de l'atelier. Le thème est d'abord recherché dans la bibliothèque de contenus pédagogiques déjà rédigés (hors-ligne) ; s'il n'y est pas encore, le contenu est généré par l'API Claude à partir de votre clé — la seule étape de toute l'application où des données quittent votre navigateur.

Thèmes déjà disponibles hors-ligne (0)

Si votre thème correspond à l'un de ceux-ci, le support est généré sans appel réseau. Sinon, l'API Claude prend le relais (clé requise).

    À raison d'environ minutes par diapositive de contenu, ça fixe le nombre de diapositives demandées.

    Vos propres illustrations, réparties sur les diapositives générées — prioritaires sur la bibliothèque d'illustrations. Utile quand le contenu généré (surtout par l'API) est rédigé avec un phrasé différent de vos anciens PPTX, ce qui peut empêcher la correspondance automatique de trouver une image pertinente.

    Stockée uniquement dans ce navigateur (jamais envoyée ailleurs qu'à l'API Anthropic au moment de générer). Nécessaire seulement si le thème demandé ne correspond à aucun contenu déjà rédigé dans la bibliothèque hors-ligne — dans ce cas, le support est généré sans appel réseau et cette clé n'est pas utilisée.

    À cocher si vous voulez un contenu généré (plus détaillé, adapté à vos observations) plutôt que la fiche de référence courte déjà rédigée — nécessite la clé API ci-dessus.

    Déposez un PPTX pour n'en récupérer que les illustrations, sans générer de support — chaque image ajoutée à la bibliothèque persistante, prête à réutiliser ailleurs dans l'app. Fonctionne sur n'importe quel PPTX, pas seulement ceux au format "atelier" attendu par les autres modes.
